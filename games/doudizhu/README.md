- 🎯 经典斗地主玩法
- 🤖 智能AI对手
- 📱 响应式设计
- 🎨 精美的视觉效果
- ⌨️ 鼠标点击选牌出牌

## 🚀 快速开始

### 本地运行

直接在浏览器中打开 `index.html` 文件即可开始游戏。

```bash
# 或使用本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 🎮 游戏规则

### 基本规则
- 三人游戏，一人为地主，两人为农民
- 地主先出牌，然后轮流出牌
- 农民合作对抗地主
- 任意一方出完牌即获胜

### 牌型说明
| 牌型 | 说明 |
|------|------|
| 单牌 | 任意一张牌 |
| 对子 | 两张相同点数的牌 |
| 三张 | 三张相同点数的牌 |
| 三带一 | 三张 + 一张单牌 |
| 顺子 | 五张及以上连续点数的牌 |
| 炸弹 | 四张相同点数的牌 |
| 王炸 | 大王 + 小王（最大牌型）|

### 操作方式
- **点击牌**：选中/取消选中
- **出牌按钮**：出选中的牌
- **不出按钮**：跳过本轮
- **重置按钮**：取消所有选中
